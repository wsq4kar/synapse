## Зачем

У вас есть подписка Claude, подписка ChatGPT и ключ Gemini, и у каждой свой сайт, свои лимиты и свои вкладки. Synapse собирает их за **одним полем ввода**:

- **Код и файлы** отдаёт настоящему агенту на вашем компьютере: **Claude Code**, **Codex**, **Antigravity CLI** или **OpenCode**. Агент работает под вашим входом, то есть по вашей подписке, без доплат.
- **Чат, картинки и видео** отправляет в **Gemini API** (Gemini, Nano Banana, Veo) или в **OpenRouter** — сотни моделей по одному ключу.
- Если один агент упёрся в лимит или ошибся, задача **сама переходит к следующему**.

Всё локально: чаты, настройки и ключи хранятся на вашем ПК. Сервера Synapse нет.

## Возможности

- **Умная маршрутизация.** Synapse сам выбирает исполнителя, но можно выбрать агента и конкретную модель вручную.
- **Четыре агента для кода:** Claude Code, Codex, Antigravity CLI и OpenCode. У каждого свои модели и свой порядок подстраховки, а сессии продолжаются с того же места.
- **Расширения.** Одна страница для MCP-серверов, коннекторов, скиллов и плагинов всех четырёх агентов. Сервер включается для Claude Code, Codex, Antigravity или OpenCode одним нажатием. GitHub, Notion, Linear, Figma, Jira, Sentry, Stripe и Supabase подключаются в пару кликов. Скиллы пишутся во встроенном редакторе. Плагины Claude Code ставятся из маркетплейсов, а MCP-серверы из официального реестра. Всё записывается в настройки самих агентов, поэтому работает и в терминале.
- **Арена.** Кнопка «Арена» во вкладке «Код»: маленькая модель пишет бриф, большие модели (Opus, GPT-6, Gemini) предлагают планы, спорят до согласия (до 3 кругов), каждая пишет свой вариант в отдельной копии папки и анонимно голосует за лучший. Победитель исправляет найденное, а вы применяете итог одной кнопкой. Пока не нажать «Применить», ваша папка не меняется.
- **Субагенты и режим «Команда».** Части задачи выполняются параллельно, и у каждой части своя живая карточка.
- **Видимые рассуждения.** Видно, как модель думает. Текст печатается плавно, с проявлением слов.
- **Рабочее место:** дерево файлов, мгновенное превью (HTML, код, Markdown, PDF, медиа) и встроенный **терминал PowerShell**. Список файлов можно спрятать, а превью развернуть на всю панель.
- **Статистика** как в Codex: токены за всё время, рекорд за день, самая долгая задача, серии дней, карта активности, любимые модели.
- **Модели вводить не нужно:** списки лежат в [`src/main/models.json`](src/main/models.json) и обновляются с GitHub.
- **Токены и лимиты:** заполненность контекста, новые токены отдельно от кэша, лимиты подписок **Claude и Codex** (5 часов и неделя).
- **Сеть:** системная, через HTTP-прокси или через SSH-туннель. Есть строгий режим, где нейросети выходят в интернет *только* через ваш прокси, и правила брандмауэра Windows.
- **Внешний вид:** светлая и тёмная тема, пять шрифтов, размер текста, цвет акцента, ширина переписки, режим Ultra, уровни усилия, ASCII-фон и питомцы. Интерфейс на русском и английском.

## Установка

1. Скачайте `Synapse-Setup-x.y.z.exe` в **[Releases](https://github.com/wsq4kar/synapse/releases)**.
2. Запустите установщик и выберите язык. Права администратора не нужны.
3. Установщик не подписан, поэтому SmartScreen может предупредить: нажмите «Подробнее», затем «Выполнить в любом случае».

## Быстрый старт

1. **Настройки → Ключи API**: вставьте ключ из [Google AI Studio](https://aistudio.google.com/apikey) и/или [OpenRouter](https://openrouter.ai/keys).
2. **Настройки → Агенты**: установите хотя бы один CLI, войдите в аккаунт и нажмите «Проверить снова».

| Агент | Установка | Вход |
|---|---|---|
| Claude Code | `npm i -g @anthropic-ai/claude-code` | `claude auth login` |
| Codex | `npm i -g @openai/codex` | `codex login` |
| Antigravity CLI | `irm https://antigravity.google/cli/install.ps1 \| iex` (PowerShell) | запустите `agy` один раз |
| OpenCode | `npm i -g opencode-ai` | `opencode auth login` (бесплатные модели работают без входа) |

Если Antigravity недоступен в вашем регионе, обход [AGUnlocker](https://github.com/confeden/Antigravity) работает с Synapse без настройки: когда он установлен, `agy` идёт через него, а не через прокси Synapse.

Горячие клавиши: `Ctrl+2` открывает сессию кода, `Ctrl+U` включает Ultra, `Ctrl+E` меняет уровень усилия, `Ctrl+J` открывает рабочее место, `Ctrl+,` открывает настройки.

## Сборка из исходников

```bash
git clone https://github.com/wsq4kar/synapse.git
cd synapse
npm install
npm start
node scripts/check.js     # проверка синтаксиса
npm run dist              # установщик (на Windows)
```

Тег вида `v0.1.10` запускает сборку установщика в GitHub Actions и публикует релиз.
